## 比赛怎么找

1. CTFtime 日历
2. 牛客 CTF 赛事页
3. 各战队公众号（XCTF、春秋、各省赛）
4. 跟着西电战队打校内赛 / 联赛 ← 最省事，有人带

## 赛后 48 小时内做完这 4 件事

1. 3–5 道题写成 md（**趁还记得**）
2. 成绩截图或榜单链接存进仓库（截图放 `images/`）
3. 没做出来的题也列一条"待补"——这是下次的题源
4. 写 3 行复盘：这次哪类题卡住了？为什么？

## 写给自己的两条规矩

1. **只写授权范围内的题**。CTF、公开靶场、厂商 SRC 的公开计划；不扫公网，不碰未授权的系统。
2. **题解只写自己真做过的**。抄来的解法不算成果。
